## Give permission when you are ready

Open **Settings → SMS Import**. MET needs SMS read permission to look for transaction messages. Review the in-app explanation before granting access.

SMS formats differ across banks and senders. A parsed message is a starting point, so check its details before treating it as a completed transaction.

## Review a candidate transaction

1. Open the SMS import screen and review the available transaction messages.
2. Check the extracted amount, date, account, and transaction type against the original message.
3. Choose the right category and update the description if needed.
4. Approve or save the entry using the available review action.

Before creating a record, check whether you already added that transaction manually.

## Understand automatic import

When you enable automatic import, MET can create pending entries for review. Pending entries are distinct from completed transactions and are not finalized spending in the monthly overview.

Use the notification review flow when prompted to approve, update, or discard an imported entry. Correct the extracted values first if they do not match the real transaction.

## When a message is not recognized

Record the transaction manually. For parser issues, contact support with your app version and a description of the message format. Remove account numbers, balances, names, and other private information from any example you choose to share.
