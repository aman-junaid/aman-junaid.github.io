## Create a backup

Open **Settings → Data Backup & Restore**. Review the available backup destination and create a backup using the options shown in your installed version.

Wait for completion. Check **Backup history** and verify the backup file or destination before relying on it.

## Make the copy useful

- Keep a backup somewhere you can access if your phone is lost or replaced.
- If you use scheduled backups, review the selected frequency, destination, and retention settings.
- Check backup history periodically. A configured schedule is not proof that the latest backup succeeded.

## Before a restore

Create a fresh backup of your current data first. Confirm that you selected the intended backup and review any restore explanation or confirmation shown by MET. Do not assume restoring will merge records with your current data.

After restoration, check your accounts, a few recent transactions, and the relevant monthly totals.

## Google Sheets and backups serve different purposes

[Google Sheets export]({{ '/guides/google-sheets/' | relative_url }}) is useful for working with transaction data in a spreadsheet. Use MET’s backup and restore tools for the app’s backup workflow.

> Back up before changing devices, reinstalling MET, or importing spreadsheet changes. Keep the existing copy until you have checked the result.
